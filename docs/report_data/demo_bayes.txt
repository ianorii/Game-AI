1. Prior Probabilitas Banjir : P(Banjir) = 0.1
2. Likelihood Bukti Berita   : P(Berita | Banjir) = 0.9
                               P(Berita | ~Banjir) = 0.1

[HASIL PERHITUNGAN BAYES]
  P(E) = P(Berita) = (0.9 * 0.1) + (0.1 * 0.9)
                   = 0.1800 (Persis 0.18)
  Posterior P(Banjir | Berita) = (0.9 * 0.1) / 0.1800
                               = 0.5000 (Persis 0.5)

[KEPUTUSAN SEBELUM ADA BUKTI (HARI BIASA)]
  EV(Pintas)      = 0.9 * 10 + 0.1 * (-20) = 7.0
  EV(Jalan Utama) = 1.0 * 6 = 6.0
  MEU Rekomendasi : Pilih 'Pintas' (Nilai: 7.0)

[KEPUTUSAN SETELAH MENDENGAR BERITA BANJIR]
  EV(Pintas | Berita) = 0.5 * 10 + 0.5 * (-20) = -5.0
  EV(Jalan Utama)     = 6.0
  MEU Rekomendasi     : Berubah ke 'Jalan Utama' (karena 6.0 > -5.0)

[BUKTI TAMBAHAN: CUACA CERAH]

  P(Banjir | Cerah) = (0.1*0.1) / 0.8200 = 0.012195 (~0.0122)
